# عروض د. محمد عطية

موقع عروض تقديمية يعمل من الرابط مباشرة، ويمكن تعديله من المتصفح.

## التقديم
- افتح الرابط، ثم اختر العرض.
- **F** ملء الشاشة · **P** نافذة ملاحظات المتحدث والمؤقت · **B** شاشة سوداء · الأسهم أو جهاز التحكم للتنقل.

## التعديل من المتصفح
1. افتح العرض واضغط زر **✎** أسفل يسار الشاشة (أو حرف **E**).
2. انقر على أي نص لتعديله، وعلى أي صورة لاستبدالها بصورة من جهازك.
3. من اللوحة الجانبية: نسخ شريحة، حذفها، تقديمها أو تأخيرها، إضافة شريحة جديدة، تعديل ملاحظات المتحدث، تغيير التصميم (ليل المسجد · حجر المدينة · الجذور والفروع).
4. اضغط **حفظ ونشر على الرابط**. يظهر التعديل لكل من يفتح الرابط خلال دقيقة تقريبًا.

نص القرآن الكريم مقفل في وضع التعديل حفاظًا على دقته. لتغييره يُعدَّل الملف مباشرة.

## مفتاح GitHub (مرة واحدة لكل متصفح)
1. GitHub ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token.
2. Repository access: **Only select repositories** ← هذا المستودع فقط.
3. Permissions ← Repository permissions ← **Contents: Read and write**.
4. انسخ المفتاح، ثم في وضع التعديل اضغط «إعداد مفتاح GitHub» والصقه. يُحفظ في متصفحك فقط.

## عرض جديد لمسجد أو مركز آخر
في وضع التعديل اضغط **نسخة جديدة لمسجد أو مركز آخر…**، واكتب الاسم ورابطًا قصيرًا بالإنجليزية.
يُنشأ عرض مستقل برابطه الخاص، ويظهر في الصفحة الرئيسية. بعدها افتحه وعدّل الاسم والشعار والصور والنصوص.
